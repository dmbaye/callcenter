# Les motifs de pause

Les motifs de pause sont les raisons proposées aux agents sous **Non prêt** dans leur menu de statut : *Déjeuner*, *Formation*, *Réunion*… Ils apparaissent dans la supervision et dans le [journal des agents](/help/journal-des-agents), ce qui permet de savoir où passe le temps de pause.

## Gérer la liste

Dans **Paramètres → Motifs de pause** (administrateurs) :

- **ajoutez** un motif ;
- **renommez**-le ;
- **réordonnez** la liste : l'ordre est celui du menu des agents ;
- **supprimez** un motif qui ne sert plus.

Une nouvelle organisation démarre avec une liste de motifs courants, à adapter à votre fonctionnement.

## Conseils

- Gardez une liste courte (5 à 7 motifs) : les agents choisissent plus vite et les statistiques restent lisibles.
- Créez des motifs qui correspondent à des décisions : « Formation » et « Tâche administrative » se pilotent différemment.
- Inutile de créer un motif « Réunion vidéo » : l'application le pose automatiquement quand un agent rejoint une réunion.

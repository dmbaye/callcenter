# Travailler une campagne

Une campagne est une liste de contacts à appeler : relance clients, prospection, enquête, recouvrement… Le **poste agent** (menu **Campagnes**) réunit tout ce qu'il faut pour les appeler : la fiche du contact, le script et la qualification.

## Ouvrir le poste agent

Dans le menu, cliquez sur **Campagnes**. Les agents arrivent directement sur **Poste agent — campagnes**, avec les campagnes auxquelles ils sont affectés (**Mes campagnes**). Les compteurs du jour (Appels, Joints, Qualifiés) s'affichent en haut.

## Appeler les contacts

Le fonctionnement dépend du mode choisi par le superviseur :

| Mode | Ce que vous faites |
| --- | --- |
| **Aperçu (preview)** | Cliquez sur **Contact suivant**, lisez la fiche, puis **Appeler**. Vous décidez quand l'appel part. |
| **Progressif** | Le système compose pour vous dès que vous êtes libre ; l'appel arrive dans le softphone quand le contact décroche. |
| **Power (multi-lignes)** | Le système compose plusieurs numéros à la fois et vous passe le premier qui décroche. |

Restez en **Prêt** pour recevoir les appels des modes Progressif et Power.

## Le script

Le script de la campagne s'affiche à côté de la fiche. Les informations du contact (nom, entreprise, colonnes importées) y sont remplacées automatiquement.

## Le questionnaire

Si la campagne a un questionnaire, il s'affiche sous le script. Posez les questions dans l'ordre : celles qui dépendent d'une réponse apparaissent d'elles-mêmes.

- **Terminer le questionnaire** vérifie que les questions obligatoires ont une réponse.
- **Enregistrer le brouillon** garde les réponses sans les vérifier. Le brouillon est aussi enregistré quand vous qualifiez l'appel.
- Si le contact est rappelé plus tard, vous retrouvez ses réponses et reprenez là où il s'était arrêté.

## Qualifier

À la fin de l'appel, choisissez un **code de qualification** puis **Valider**. Selon le code :

- le contact est **terminé** (succès ou échec définitif) ;
- il sera **rappelé automatiquement** plus tard ;
- un **rappel planifié** est créé à la date choisie dans **Rappeler le** ;
- il est ajouté à la liste **Ne pas appeler** et ne sera plus jamais composé.

## Les demandes de rappel

Quand un client en attente dans une file demande à être rappelé, sa demande arrive dans le poste agent des membres de cette file, comme un contact à rappeler. Traitez-la comme un contact de campagne.

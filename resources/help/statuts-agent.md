# Les statuts agent

Le menu de statut, en haut à droite de l'écran, décide si les appels des files vous sont présentés. Il affiche aussi depuis combien de temps vous êtes dans le statut. Votre choix est conservé si vous rechargez la page ou ouvrez un second onglet.

## Les statuts

| Statut | Appels des files | Appels directs | Quand l'utiliser |
| --- | --- | --- | --- |
| **Prêt** | Oui | Oui | Vous êtes disponible. |
| **Non prêt** | Non | Oui | Pause, avec un motif : Déjeuner, Formation… |
| **Post-appel** | Non | Oui | Vous terminez les notes de l'appel précédent. |
| **Ne pas déranger** | Non | Non, ils sont refusés | Vous ne devez être interrompu sous aucun prétexte. |
| **Déconnexion** | Non, vous sortez des files | Oui | Fin de journée, sans fermer l'application. |

Les motifs de **Non prêt** sont choisis par votre administrateur. Ils apparaissent dans la supervision et le [journal des agents](/help/journal-des-agents).

## Raccourcis clavier

| Raccourci | Statut |
| --- | --- |
| `Ctrl` + `Alt` + `R` | Prêt |
| `Ctrl` + `Alt` + `N` | Non prêt |
| `Ctrl` + `Alt` + `Z` | Post-appel |

Les raccourcis fonctionnent sur les claviers AZERTY et QWERTY, et sur Mac avec `Ctrl` + `Option`.

## Changements automatiques

Certains événements changent votre statut sans que vous ayez à le faire :

- **Fin d'un appel** : vous passez en *Post-appel* le temps de qualifier l'appel, puis revenez en *Prêt* dès que le résultat est enregistré (ou que vous passez l'étape).
- **Réunion vidéo** : quand vous rejoignez une réunion, vous passez en **Non prêt – Réunion vidéo**, pour que les appels des files ne sonnent pas pendant que vous êtes en visioconférence. Si vous aviez déjà choisi une pause (Non prêt avec un motif, Ne pas déranger ou Déconnexion), elle est conservée.

> **Important :** en quittant une réunion, vous **restez en Non prêt**. Une notification vous propose **Repasser Prêt** : cliquez dessus, ou changez votre statut dans le menu, pour recevoir à nouveau les appels.

# Le softphone

Le softphone est le téléphone de l'agent, directement dans le navigateur. Il apparaît pour les membres qui ont un poste SIP dans l'organisation.

## Ouvrir le softphone

Cliquez sur le **bouton téléphone rond** en bas à droite de l'écran. Le petit point sur le bouton indique l'état du poste :

- **vert** : le poste est connecté au serveur téléphonique, vous pouvez appeler et recevoir ;
- **orange** : le poste se connecte ou est hors ligne. Vérifiez votre connexion internet et rechargez la page si cela dure.

En haut du softphone, le badge résume la situation : *Prêt*, *Entrant*, *Calling* (appel sortant en cours) ou *Active* (en communication).

> Au premier appel, le navigateur demande l'accès au **microphone** : acceptez, sinon votre correspondant ne vous entendra pas.

## Recevoir un appel

Un appel entrant affiche une carte **Appel entrant** avec le numéro et, s'il est connu, le nom du client, et la sonnerie retentit. Cliquez sur **Répondre** ou **Decliner**.

Les appels des files ne vous sont présentés que si votre statut est **Prêt**. Voir [Les statuts agent](/help/statuts-agent).

## Passer un appel

1. Ouvrez le softphone.
2. Tapez le numéro dans **Saisissez un numéro** ou utilisez le clavier.
3. Cliquez sur **Appeler**.

Le bouton d'effacement retire le dernier chiffre ; un double-clic efface tout. Depuis le tableau de bord, le bouton **Rappeler** d'un appel récent compose le numéro pour vous.

## Appeler un collègue

Sous le numéro, l'onglet **Collègues** liste tous les membres qui ont un poste, avec leur fonction et leur numéro de poste. Cherchez par nom, poste ou service, puis cliquez sur le téléphone vert pour appeler (ou sur la ligne pour seulement composer le numéro).

La pastille indique le statut choisi par le collègue : **vert** Prêt, **orange** Non prêt ou Post-appel, **rouge** Ne pas déranger, **gris** hors ligne (application fermée). Les collègues joignables sont en tête de liste ; le bouton d’appel est grisé pour ceux qui sont hors ligne ou en Ne pas déranger. Si l’appel n’aboutit pas, un message en indique la raison : déjà en ligne, pas connecté… Les appels entre postes sont gratuits.

## Pendant l'appel

| Bouton | Effet |
| --- | --- |
| Micro | Coupe votre micro (*Muted*) ; le client ne vous entend plus. |
| Pause | Met le client **en attente** (*On hold*) ; cliquez à nouveau pour **reprendre**. |
<!-- centre-appels -->
| Transfert | **Transférer vers une file** : l'appel part vers la file choisie et vous êtes libéré. |
<!-- /centre-appels -->
| Téléphone rouge | Raccroche. |

## Après l'appel

<!-- centre-appels -->
Une carte **Appel terminé** vous demande le résultat de l'appel. Voir [Qualifier un appel](/help/qualifier-un-appel). Si vous prenez ou passez un autre appel avant de le qualifier, la carte revient ensuite : chaque appel terminé attend son résultat, du plus ancien au plus récent.
<!-- /centre-appels -->

## En cas de problème

- **Pas de son** : vérifiez que le casque est choisi comme micro et haut-parleur dans le navigateur, et que l'accès au micro est autorisé (icône à gauche de l'adresse).
- **Le point reste orange** : rechargez la page. Si cela persiste, prévenez votre administrateur : le poste peut être mal configuré.
<!-- centre-appels -->
- **Fermer l'onglet** vous retire des files. Rouvrez l'application pour recevoir à nouveau les appels.
<!-- /centre-appels -->
